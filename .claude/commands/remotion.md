## Remotion usage notes

- Scaffold: `npx create-video@latest`
- Preview: `npx remotion studio src/index.ts`
- Render: `npx remotion render src/index.ts MyComposition out/video.mp4`
- Add compositions in `src/`, register in `src/Root.tsx`
- Use `<Sequence>` for multi-scene videos
- Use `spring()` + `interpolate()` for animations
